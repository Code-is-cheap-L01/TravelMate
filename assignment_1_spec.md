# Assignment 1: Mobile App Project Set-Up

## 1. Objective

In this assignment, you will establish the foundation for your Mobile App Development project by:

- Setting up a GitHub Organization for your team.
- Creating a well-structured wiki to host all project documentation.
- Conducting initial research and planning activities.

This early stage ensures your team develops good practices for collaboration, documentation, and project tracking throughout the course.

The deadline for this assignment is announced on your class site (e.g., L01).

## 3. Assignment Details

### 3.1. Set Up GitHub Organization and Project

#### Create a GitHub Organization

- One member (usually the group leader) should create a GitHub Organization named after your group.
- Invite all other group members as collaborators.

#### Designate Group Leader

- Assign the group leader as the **Organization Owner/Administrator**.
- This member is responsible for:
  - Managing repositories.
  - Managing wiki access.
  - Managing project settings.

#### Create a GitHub Project for Task Management

- Use **GitHub Projects (beta)** as your primary project management tool.
- Set it up using the **Board** or **Table** view to follow the **Scrum methodology**.
- Define basic columns such as:
  - Backlog
  - To-Do
  - In Progress
  - Review
  - Done

#### Define Milestones

Add milestones to represent major stages of development, such as:

- **MVP Release**
- **Beta**
- **Final Presentation**

---

### 3.2. Prepare Wiki Content on GitHub Organization

All project information for this assignment must be written and organized in the **GitHub Wiki** of your Organization, **not in external documents**.

Populate your wiki with the following sections:

#### Project Overview

- **Project Name**
- **Slogan**
- A short statement describing the purpose and goals of your mobile app project.

#### Market Research

- Research at least **5 similar products** currently available in the market.
- Summarize insights and emphasize what gaps or opportunities your solution addresses.

#### Business Canvas

- Present your **Business Model Canvas (BMC)** clearly using a diagram or table.
- Highlight your **Unique Value Proposition (UVP)** compared to existing products.

#### MVP Features

- Identify and justify the **Minimum Viable Product (MVP)** features.
- Use the **Impact-Effort Matrix** to prioritize features.
- Explain why these features are critical for the first release.

#### User Flows

- Create and include user flow diagrams for at least **two of the most crucial MVP features**.
- Show how typical users will interact with these features step-by-step.

---

### 3.3. Organize the Project Plan in GitHub Projects

#### Leverage Wiki Information

Use your research and feature list from the wiki to plan your development activities.

#### Set Up Tasks and Timelines

In GitHub Projects:

- Create tasks for each feature or module.
- Assign each task to team members.
- Link each task to the appropriate milestone.
- Ensure the project board reflects your **Scrum workflow and progress**.
